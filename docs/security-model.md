# 安全性モデル

`agent-notes-mcp` はローカル stdio MCP サーバーです。HTTP endpoint を公開せず、それ自体がノート内容を外部サービスへ送信することもありません。

## root によるアクセス制御

- 検索・読込みは、設定した `read_roots` 配下の Markdown ファイルだけに限定されます。
- 作成・追記・置換・移動は、設定した `write_roots` 配下だけで行えます。書込み root は読込み可能な root の内側である必要があります。
- 絶対パス、`..` を含む相対パス、設定 root の外へ解決されるシンボリックリンクは拒否します。

## 安全な書込み

- 既存ノートの置換・移動には、事前の読込みで得た SHA-256 が必要です。手動編集や同期による競合を検出し、黙って上書きしません。
- 移動先にあるファイルを上書きしません。
- 削除は意図的に提供しません。
- 管理ブロック更新と一括更新は、書込み前に対象全体を検証します。

設定した root がアクセス境界です。書込み root は必要最小限にし、資格情報などの機密情報を含むノートは、不要な MCP クライアントからアクセスできる root に置かないでください。
