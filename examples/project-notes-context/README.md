# project-notes-context スキル例

このディレクトリは、Codex が Git リポジトリの作業を始めるときに、対応する private ノートを参照するためのスキル例です。チーム内で共有できる、実用寄りの運用ルールを示しています。

`SKILL.md` をそのまま使うのではなく、`notes-work` という root ID、ノートの配置、更新方針を自分の環境へ合わせて確認・調整してください。実際のノート内容や認証情報をこのディレクトリへ入れないでください。

この例には、読込みに加えて、管理ブロックの更新、SHA-256 を使う安全な置換、一括更新、activity log、ブランチ別ノートと inbox の扱いも含めています。不要な節は削って構いません。ノートを作成・更新する場合は、ユーザーの明示的な依頼または合意を必要とするようにしてください。

`AGENTS.md.example` は、このスキルを作業開始時に呼び出すための最小の起点です。
